# Textbook Analyzer

**English** · [Русский](README.ru.md)

A browser tool for analysing English language textbooks. It rates exercise instructions and learning texts against linguistic and methodological criteria and shows the results as heat maps, statistics and automatically generated conclusions. The tool does not deliver a final verdict; it shows where problems concentrate so that an expert can look closer.

The tool has two modes built on one shared core:

- **Instructions** – exercise instructions (Read the text and…, Work in pairs…, Complete the sentences…);
- **Texts** – reading texts, listening scripts, dialogues and the language material of exercises.

Because both modes share lemmatisation, CEFR vocabulary and grammar levels and the textbook vocabulary list, an instruction and the text of the same exercise can be compared on one scale – for example, to check whether the instruction is harder than its text (criterion R6).

Prototype v1, November 2026.

## How to run

Open `index.html` in a browser (Chrome, Safari, Firefox). No server or installation is needed; the internet is used only for fonts and, optionally, for the Groq language model. The tool can also be published on GitHub Pages. On first launch a sample loads – two fictional textbooks with 31 instructions and 10 texts. Data, settings and expert ratings are stored in the browser (localStorage).

The **RU / EN** buttons in the header switch the interface language. On first launch the language follows the browser language. The whole tool is translated – interface, conclusions, card comments, rubric, the Method tab and the prompts for the language model. Calculations do not depend on the language.

## Tabs

- **Heat map** – rows are exercises or units, columns are criteria, colour shows how pronounced a problem is (0-1). The rating source can be switched between algorithm, expert, model and expert-model difference. Clicking a row opens a card with the instruction in close-up (words and grammar above the level highlighted), indicators, comments, a draft rewording and rubric ratings.
- **Statistics** – summary indicators, vocabulary profile, textbook comparison map, maps by unit and task type, words and constructions above the level, metalanguage, consistency of wording. Export of results (CSV) and the full protocol (JSON).
- **Conclusions** – text generated by rules from the calculated indicators.
- **Recommendations** – methodological recommendations for the teacher and the textbook author at the textbook, unit and exercise level, with priority and source; optional refinement by a language model; export to .md and CSV.
- **Data** – import from a textbook (PDF, Word, web page), manual input or a CSV table, the textbook vocabulary list, an optional syntactic parse.
- **Settings** – Groq key, level (from the data or one level for all – teacher mode), strictness profile, vocabulary tolerance, reference lists, weights, length norms (including calculation from the corpus).
- **Rubric** – expert rating, language model rating (Groq or any chat), inter-rater agreement (weighted Cohen's kappa).
- **Method** – formulas and reference versions.

## Import from a textbook

The block at the top of the Data tab reads a textbook and finds units, exercise numbers and instructions automatically. No JSON or CSV has to be prepared by hand.

- **Sources** – PDF (pdf.js, works from a page opened as a file), Word .docx (bold, styles and Word auto-numbering are taken into account), a web page (saved .html, content pasted from the clipboard – this also works for pages behind a sign-in such as Moodle – or loading by address if the site allows it), .txt.
- **Detection** – units (Unit, Lesson, Module, 1A headings), exercise numbers and sub-items (1, 2a, Ex. 3), instructions by an instruction verb at the start (about 120 verbs, including In pairs, Now, Before you read…) and by font emphasis. In PDFs lines are rebuilt from coordinates, two-column pages are recognised.
- **Review** – each found instruction is marked confident, likely or doubtful; unit, number and text can be edited before the rows are added to the table.
- **Language model** – optional refinement via Groq or any chat; every instruction returned by the model is checked against the source text.
- Scanned PDFs without a text layer and the old .doc format are not read.

## Criteria

**Instructions**

| Code | Criterion | How it is calculated |
|---|---|---|
| A1 | Vocabulary level | weighted share of units above the level (0.5 for +1 level, 1 for +2 and more), normalised between tolerance and saturation |
| A2 | Grammar | rules find constructions and compare their level with the target (0.5 for +1, 1 for +2) |
| A3 | Length and density | excess over level norms for words, words per sentence and number of actions, mean of the three |
| A4 | Metalanguage | terms above the level acceptable without explanation, plus a density surcharge |
| A5 | Consistency | share of instructions of the same type with a different wording within a textbook |
| A6 | Readability | Flesch-Kincaid, for reference only |
| A7 | Vocabulary already introduced | removes an A1 flag if the word is in the textbook vocabulary list or occurred in previous instructions |
| D1 | Parameters | whether writing and speaking tasks state length, time or number of answers |
| D3 | References | whether the exercise the instruction refers to exists |
| D4 | Ambiguity | heuristic signs (match without a pair, gaps without a word source) |
| PCI | Perception complexity index | weighted mean of A1-A4 |

Rubric criteria rated by an expert and a language model – R1 clarity, R2 instruction verb, R3 exercise type, R4 communicative situation, R5 model, R6 level of instruction and task, R7 task appropriateness, D1 parameters, D2 mode of work, D4 unambiguity, D5 language of instruction. Unit rubric – L1 sequence of exercises, L2 match with the unit aim.

**Texts**

| Code | Indicator | How it is calculated |
|---|---|---|
| T1 | Vocabulary | coverage – share of tokens at or below the declared level; 0 at ≥ 98 %, 0.5 at 95 %, 1 at ≤ 90 % |
| T2 | Grammar | weighted constructions above the level per 100 words |
| T3 | Syntax | excess over level norms for sentence length and subordinate clauses per sentence |
| T4 | Readability | Flesch-Kincaid relative to the level norm, for reference (weight 0) |
| L | Text level | weighted mean of vocabulary, grammar and syntax levels, rounded to half a level |
| TCI | Text complexity index | weighted mean of T1-T4 on the same 0-1 scale as PCI |
| R6 | Instruction-text pair | how far the instruction's vocabulary or grammar is above the text's and above the declared level |

Rubric for texts – TR1 topic and task, TR2 authenticity, TR3 cultural accessibility, TR4 coherence, TR5 level of text and task, TR6 suitability for the skill.

Full formulas are on the Method tab.

## Exercise methodology

Each instruction receives an exercise type on the scale of learner freedom used in Russian methodology – substitution, transformation, conditionally communicative and genuinely communicative (Solovova, 2006, p. 32), which corresponds to controlled, guided and communicative practice. The tool also assigns the stage of work on material (presentation, practice, production), the text stage (pre-, while-, post-text) and the unit of material. From the order of exercises it builds a unit profile and marks jumps, returns, a missing production stage and text-stage order problems. The unit sequence index (USI, 0-1) points to units for expert review; it is not a verdict, since task-first sequences (boomerang, test-teach-test) are legitimate. Task appropriateness (R7) and unit sequence (L1, L2) are rated by experts and the language model. The unit aim is an optional `aim` column. The rationale is in section 7 of `docs/methodology.md` (in Russian).

### Methodological recommendations

Based on the analysis, the tool generates methodological recommendations for two addressees – the teacher (how to work with the textbook in class) and the textbook author (what to change in the textbook) – at the textbook, unit and exercise level. 34 rules (rec-0.1) link a feature – an instruction criterion, the exercise type, a sequence mark, text difficulty – to a recommendation and a source (Solovova, 2006; Gez et al., 1982; Harmer; Scrivener; CELTA; TKT). Each recommendation has a priority (1 – prevents doing the task, 2 – makes it harder, 3 – for reference). On request a language model makes the unit recommendations specific – a technique and an oral instruction for the teacher, a new instruction wording or a draft exercise for the author. Recommendations are shown on the Recommendations tab and in the cards and can be exported to Markdown and CSV. The rationale is in section 8 of `docs/methodology.md` (in Russian).

## Language model (optional)

- **Via Groq** – create an API key at console.groq.com and enter it on the Settings tab. The key is stored only in the browser and never goes into exports or the repository.
- **Manually** – the prompt is copied into any chat with a model (Claude, ChatGPT, GigaChat, YandexGPT, etc.), and the JSON answer is pasted back.

Model ratings are treated as reliable only after checking against independent expert ratings.

## Syntactic parse (optional)

Without a parse, grammar and subordinate clauses are found by rules. For research samples a parse can be prepared with spaCy or Stanza: download the texts on the Data tab, run `python3 tools/parse_texts.py texts-for-parsing.jsonl -o parsed.conllu` and load the result. Any CoNLL-U file (for example from UDPipe) also works.

## Data formats

- **Instructions CSV** – fields `book;level;unit;ex;text` (required) and `section;aspect;audience;l1;exercise_text;aim;publisher;year` (optional; `aim` – unit aim). Separator – semicolon, comma or tab. See `examples/sample-instructions.csv`.
- **Manual input** – one instruction per line; a line `Unit 2` starts a unit, `3. Complete the…` sets exercise 3.
- **Textbook vocabulary list** – CSV `book;unit;word` (book optional).
- **Texts CSV** – `book;level;unit;ex;text_type;title;source;text`; text type is reading, listening, dialogue or material. See `examples/sample-texts.csv`.
- **Additional vocabulary list** – CSV with `headword` (or `word`) and `CEFR` (or `level`), e.g. Oxford 3000/5000.

## Limitations

- Lemmatisation and grammar (without a parse) are rule-based; misses and false positives are possible, especially in long instructions. The accuracy of the algorithmic criteria should be checked on a manually annotated sample.
- The CEFR-J Wordlist was compiled for the Japanese context of English teaching; some levels differ from the English Vocabulary Profile.
- The metalanguage dictionary, the dictionary of instructional senses, length norms, text norms and weights are working values to be calibrated on a corpus and agreed with experts.
- Krippendorff's alpha for three or more experts and OCR for scanned PDFs are planned for the second version.

## Structure

```
index.html            interface and styles
js/i18n.js            interface language switch (_t function)
js/i18n-en.js         English dictionary (key – Russian phrase, value – English)
js/resources.js       references – instructional senses, irregular forms, set phrases, metalanguage, norms, task types, rubrics, text types
js/cefrj.js           built-in CEFR-J Wordlist 1.5, Octanove C1/C2 and CEFR-J Grammar Profile items
js/lexicon.js         built-in working vocabulary list (fallback)
js/core.js            shared core – lexicon, lemmatisation, tokenisation, grammar, levels, vocabulary profile, A7, readability, MTLD, statistics, kappa, CSV
js/engine.js          Instructions mode – A1-A7, D1, D3, D4, PCI, statistics, conclusions
js/method.js          exercise methodology – type on the scale of learner freedom, stage, text stage, unit of material, unit sequence and USI
js/recommend.js       methodological recommendations for the teacher and the author – rules rec-0.1 for exercises, units and textbook
js/texts.js           Texts mode – T1-T4, level estimate, TCI, paragraphs, instruction-text pairs, conclusions
js/parse.js           CoNLL-U reading and rule refinement by the parse
js/docx.js            reading .docx in the browser
js/import.js          import from a textbook – PDF, DOCX, HTML, TXT and instruction detection
js/vendor/            pdf.js 6.2.108 (Mozilla, Apache-2.0)
js/ui.js, ui-texts.js, ui-import.js, ui-method.js, ui-rec.js   interface
js/sample.js          sample data
examples/             sample instructions, texts and vocabulary list (CSV)
data/                 source CSV files of CEFR-J and Octanove with terms of use
docs/                 user guide and methodology (in Russian)
tools/parse_texts.py  spaCy or Stanza parse to CoNLL-U
tests/                reproducibility check (`node tests/regress.js`), exercise methodology cases (`node tests/method-cases.js`), recommendation cases (`node tests/rec-cases.js`), grammar test sentences, sample parse
```

The core and both engines run in the browser and in Node.js. `node tests/regress.js` compares the numbers of both modes on the sample with `tests/snapshot.json`.
