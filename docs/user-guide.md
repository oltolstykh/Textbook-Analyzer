# Анализатор учебника (Textbook Analyzer) – руководство пользователя

Nov 21, 2026 · @Oltobyru

## Назначение и запуск

Анализатор оценивает инструкции к упражнениям учебников английского языка по лингвистическим и методическим критериям и показывает, где проблемы сгущаются. Инструмент не выносит итоговый вердикт – он выделяет зоны, которые требуют экспертного взгляда.

Кому пригодится

- исследователю – для анализа корпуса учебников и сравнения серий;
- автору учебных материалов – для проверки собственных заданий;
- преподавателю – для выбора учебника и адаптации заданий под уровень группы.

### Как открыть

1. **На своём компьютере.** Откройте файл `index.html` из папки Textbook Analyzer в браузере (Chrome, Safari, Firefox). Сервер не нужен, интернет нужен только для шрифтов и для оценки через Groq.
2. **С GitHub Pages.** После публикации инструмент открывается по ссылке вида `https://<имя>.github.io/<репозиторий>/` у любого человека, без установки.

Язык интерфейса переключается кнопками RU / EN в правом верхнем углу. Переводится весь инструмент, включая выводы, рубрику, методику и промпты для языковой модели, расчёты от языка не зависят. При первом запуске язык выбирается по языку браузера.

Оба способа работают одновременно. Папка на компьютере остаётся рабочей копией – правки в ней появляются на GitHub только после загрузки.

### Из чего состоит экран

| Вкладка | Для чего |
| --- | --- |
| Тепловая карта | обзор всех инструкций по критериям, переход к карточке |
| Статистика | сводные показатели, карты учебников, уроков и типов заданий, экспорт |
| Выводы | автоматический текст по рассчитанным показателям |
| Данные | импорт из PDF, Word и веб-страниц, ввод инструкций, словник учебника |
| Настройки | ключ Groq, уровень, профиль строгости, эталоны, веса, нормы |
| Рубрика | экспертная оценка, языковая модель, согласованность |
| Методика | формулы и версии эталонов |

При первом запуске загружается пример – два вымышленных учебника (31 инструкция). С ним удобно освоить интерфейс до работы с собственным корпусом.

## Подготовка данных

Инструкции попадают в анализатор тремя путями – импортом прямо из учебника (PDF, Word, веб-страница), текстом для одного учебника или таблицей CSV для корпуса. После ввода нажмите «Анализировать».

### Импорт из учебника

Блок «Импорт из учебника» находится вверху вкладки «Данные». Готовить таблицу или JSON вручную не нужно – инструмент сам читает файл, находит уроки, номера упражнений и инструкции и показывает их списком для проверки.

1. Укажите учебник и заявленный уровень, по желанию – аспект. Для большого PDF задайте диапазон страниц, например 12-40.
2. Загрузите источник одним из способов.
   - **PDF, Word (.docx), сохранённая веб-страница (.html), .txt** – кнопка «Выбрать файл». Можно выбрать несколько файлов сразу, например отдельные уроки, найденное объединится.
   - **Учебник выложен как веб-страница** – откройте страницу, выделите всё (Cmd+A на Mac, Ctrl+A в Windows), скопируйте и вставьте в поле «Вставить со страницы», затем нажмите «Найти инструкции во вставленном». Так работает и со страницами, которые требуют входа (Moodle, электронная библиотека). Для следующей страницы повторите вставку – найденное добавится к списку.
   - **Адрес страницы** – кнопка «Загрузить по адресу». Большинство сайтов не разрешает читать свои страницы из другого места, поэтому чаще срабатывают вставка или сохранённый файл.
3. Просмотрите список. У каждой строки есть урок, номер упражнения, инструкция, материал упражнения (раскрывается под инструкцией) и оценка надёжности.
   - **уверенно** – перед инструкцией стоит номер упражнения, и она начинается с глагола-установки (Read, Listen, Complete, Work in pairs…);
   - **вероятно** – есть номер и выделение шрифтом, но нет глагола-установки, или инструкция выделена шрифтом, но без номера;
   - **сомнительно** – только глагол-установка без номера и выделения. Такие строки не отмечены, их стоит просмотреть фильтром «Сомнительные».
4. Исправьте урок, номер или текст инструкции прямо в таблице, снимите галочку у лишних строк.
5. Нажмите «Добавить отмеченные в таблицу». Строки попадут в таблицу CSV ниже (поля book, level, unit, ex, aspect, text, exercise\_text), повторы пропускаются. Пример из первого запуска заменяется вашими данными автоматически, остальные данные сохраняются, если не отмечено «Заменить загруженные инструкции». Кнопка «Скачать CSV» сохраняет найденное файлом для Excel.

Как инструмент ищет инструкции. В PDF текст собирается по строкам с учётом двух колонок, перенос слов склеивается, номер упражнения на отдельной строке относится к соседней строке той же страницы. Шрифт, которым набраны уверенно найденные инструкции, считается шрифтом инструкций, и строки этим шрифтом тоже проверяются. В Word учитываются жирное начертание, стили заголовков и автонумерация (номер списка в тексте документа не хранится, инструмент восстанавливает его сам). На веб-странице учитываются заголовки, жирный шрифт и нумерованные списки, меню и подвал сайта пропускаются. Урок распознаётся по строкам вида Unit 3, Lesson 2, Module 1, Урок 4, а также 1A, 2B в заголовке. Инструкция заканчивается перед первым пунктом упражнения (1, a), пропуском ___ или материалом.

**Если найдено не всё.** Раскройте «Если найдено не всё – уточнить языковой моделью». Через Groq модель заново просматривает текст источника частями и возвращает список инструкций, через любой чат – промпт с текстом источника копируется в чат, а ответ вставляется обратно. Каждая инструкция от модели сверяется с источником, то, чего в учебнике нет дословно, помечается как сомнительное. Сам источник не сохраняется после перезагрузки страницы, поэтому для уточнения моделью файл нужно выбрать ещё раз.

**Ограничения.** Сканированный PDF без текстового слоя не читается – сначала распознайте текст (Adobe Acrobat – «Распознать текст», ABBYY FineReader) и загрузите файл снова. Старый формат .doc нужно пересохранить в Word как .docx. Сложная вёрстка (врезки, таблицы, текст поверх картинок) может нарушить порядок строк – поэтому найденное всегда просматривает исследователь.

### Текстовый ввод

1. Выберите режим «Текст».
2. Укажите учебник и заявленный уровень, по желанию – аспект и аудиторию.
3. Вставьте инструкции, по одной в строке.

Уроки и номера упражнений распознаются по разметке строк.

```
Unit 1
1. Look at the pictures and match them with the words in the box.
2. Complete the sentences with the words from Ex. 1.
## Unit 2
1. Read the text and answer the questions.
```

Строка `Unit 2` или `## Unit 2` начинает урок, цифра с точкой в начале строки задаёт номер упражнения. Номера нужны для проверки отсылок вида Ex. 3 (критерий D3).

### Таблица CSV

Для нескольких учебников удобнее таблица. Её можно вести в Excel или Google Таблицах и сохранить как CSV. Разделитель – точка с запятой, запятая или табуляция, первая строка – заголовки.

| Поле | Обязательное | Допустимые названия | Зачем нужно |
| --- | --- | --- | --- |
| text | да | instruction, инструкция | объект анализа |
| level | да | cefr, уровень | целевой уровень (A2, B1+) |
| book | да | учебник | группировка, A5, A7 |
| unit | да | урок, lesson | карта по урокам, A7 |
| ex | да | упражнение, номер | проверка отсылок D3 |
| section | желательно | раздел | подпись в карте |
| aspect | желательно | аспект | контекст для рубрики |
| audience, l1 | желательно | аудитория, родной язык | контекст для рубрики |
| exercise\_text | желательно | текст упражнения | критерии R2, R3, R6 |
| publisher, year | по желанию | издательство, год | описание корпуса |

Образец таблицы лежит в папке `examples` (файл sample-instructions.csv). В одной ячейке – одна инструкция целиком, вместе с дополнительными указаниями (Work in pairs. Use the words from the box).

### Словник учебника

Словник снимает ложные срабатывания по лексике (критерий A7). Слово выше уровня, которое авторы ввели в этом или более раннем уроке, не считается превышением. Формат – CSV с полями `book;unit;word`, поле book можно опустить. Загрузка – в нижнем блоке вкладки «Данные».

## Настройки

Настройки применяются сразу и записываются в протокол вместе с результатами. Для исследования важно зафиксировать один набор настроек до анализа и не менять его по ходу работы.

| Блок | Что задаёт | По умолчанию |
| --- | --- | --- |
| Уровень | уровень из данных или один для всех инструкций | из данных, если не указан – A2 |
| Профиль строгости | допуск по лексике, насыщение шкалы, порог ИСВ, нормы объёма | стандартный |
| Лексика (A1) | допустимая доля слов выше уровня, слова вне списка, основной и дополнительный список | 5 %, насыщение 15 %, вне списка – B2, CEFR-J |
| Введённость (A7) | учёт словника и предыдущих инструкций | включено, 1 употребление |
| Грамматика (A2) | источник уровней конструкций, словарь инструктивных значений | English Grammar Profile |
| Сложность восприятия | веса четырёх показателей в ИСВ, пороги | 0,35 / 0,25 / 0,25 / 0,15, порог 0,40 |
| Нормы объёма (A3) | слов в инструкции, слов в предложении, действий по уровням | рабочие значения |

### Уровень – два режима

- **Из данных** – режим исследователя. Каждая инструкция сравнивается с заявленным уровнем своего учебника.
- **Задать для всех** – режим преподавателя. Инструкции любого учебника оцениваются относительно уровня конкретной группы. Так можно проверить, подойдёт ли учебник B1 для группы с уровнем A2+.

### Профиль строгости

| Профиль | Допуск, % | Насыщение, % | Порог ИСВ | Нормы объёма | Когда выбирать |
| --- | --- | --- | --- | --- | --- |
| Строгий | 3 | 10 | 0,30 | × 0,8 | младшие школьники, уровни A1-A2 |
| Стандартный | 5 | 15 | 0,40 | × 1 | большинство случаев |
| Мягкий | 8 | 20 | 0,50 | × 1,25 | взрослые с опытом изучения языка |

После выбора профиля любое значение можно уточнить вручную.

### Эталоны

- **Основной список лексики** – CEFR-J Wordlist 1.5 и Octanove C1/C2 (8 845 единиц). Дополнительный список (например, Oxford 3000/5000) загружается как CSV со столбцами headword и CEFR. Его можно добавить к основному или заменить им основной. Обязательно впишите название и версию – они попадут в протокол.
- **Уровни грамматики** – English Grammar Profile (столбец EGP в CEFR-J Grammar Profile), CEFR-J Grammar Profile или рабочая таблица. Источник для статьи нужно выбрать один раз и указать в описании методики.
- **Словарь инструктивных значений** – строка `слово; уровень; пояснение`, например `complete; A2; заполнить`. Уровень из словаря применяется, только если он ниже уровня по списку. После правки нажмите «Применить».

### Нормы по корпусу

Кнопка «Рассчитать по корпусу (P75)» берёт 75-й процентиль загруженных инструкций каждого уровня, нужно не меньше 5 инструкций уровня. Так норма становится описанием типичной инструкции вашего корпуса. Рассчитывайте нормы на полном корпусе, а не на одном учебнике, иначе учебник станет нормой для самого себя.

## Чтение результатов

Результат показан в четырёх слоях – от одного слова до сравнения учебников. Все показатели приведены к шкале от 0 (проблемы нет) до 1 (проблема выражена максимально).

### Тепловая карта

Строки – упражнения или уроки, столбцы – критерии. Чем темнее ячейка, тем сильнее выражена проблема. Штриховка одного направления означает «неприменимо» (D1 для задания на чтение), другого – «нет данных».

- Переключатель **Алгоритм / Эксперт / Модель / Расхождение** добавляет рубричные столбцы R1-R6, D1, D2, D4, D5. В режиме «Расхождение» цвет показывает, насколько расходятся эксперт и модель.
- Переключатель **Упражнения / Уроки** показывает каждую инструкцию или среднее по уроку.
- Клик по строке открывает карточку инструкции.

### Карточка инструкции

Вверху – инструкция крупным планом. Наведите курсор или нажмите на выделенное слово, чтобы увидеть его уровень, источник и возможную замену.

| Обозначение | Значение |
| --- | --- |
| светлая заливка | слово на уровень выше |
| насыщенная заливка | слово на два и более уровня выше |
| бледная нижняя полоса | слово выше уровня, но уже введено в учебнике (A7) |
| бирюзовое подчёркивание | грамматическая конструкция выше уровня |
| пунктир | термин метаязыка |
| серая нижняя линия | слова нет в списке лексики |

Ниже идут шкалы по критериям с пояснением, замечания, черновик переформулирования, рубричные оценки и подробности расчёта. Черновик составлен автоматически – инструмент разбивает инструкцию на шаги и заменяет отдельные слова. Грамматику черновика нужно проверять.

### Статистика

- Таблица по критериям – среднее, медиана, стандартное отклонение, размах и число инструкций выше порога.
- Распределение лексики – доля единиц на уровне, выше на один и на два уровня, снятых по A7.
- Карты учебников, уроков и типов заданий – средние значения по группам.
- Списки слов, конструкций и терминов выше уровня с частотой и возможными заменами.
- Единообразие формулировок – сколько разных формулировок учебник использует для одного типа задания.

Как анализировать эти цифры для статьи, подробно описано в документе «Научное обоснование и методика».

### Выводы

Инструмент собирает текст по правилам из рассчитанных показателей – общая картина, лексика, грамматика, объём, метаязык, единообразие, сгущение проблем, сравнение учебников и ограничения. Текст копируется или скачивается. Это рабочий материал для анализа, а не готовый текст статьи.

## Рубрика и языковая модель

Во вкладке «Рубрика» инструкции оцениваются по рубричным критериям R1-R6, D1, D2, D4, D5 по шкале 2 – 1 – 0 и «неприменимо». Оценить могут эксперты и языковая модель.

### Экспертная оценка

1. Введите имя или код эксперта (например, Э1).
2. Выберите инструкцию в списке или переходите кнопками «Назад» и «Далее».
3. Отметьте баллы по каждому критерию, под вопросом даны описания для баллов 2, 1 и 0.
4. Нажмите «Сохранить и далее».

Оценки модели по инструкции открываются только после сохранения своей оценки, чтобы они не влияли на эксперта. Каждый эксперт работает в своём браузере и передаёт оценки файлом – «Экспорт оценок JSON» у эксперта, «Импорт оценок JSON» у исследователя. Для этого у всех должен быть загружен один и тот же файл инструкций – идентификаторы инструкций строятся по учебнику, уроку, номеру и тексту.

### Оценка моделью – два способа

|  | Через Groq | Вручную |
| --- | --- | --- |
| Что нужно | ключ API Groq | любой чат с моделью (Claude, ChatGPT, GigaChat, YandexGPT) |
| Как работает | инструмент сам отправляет инструкции пакетами по 5 и сохраняет ответы | вы копируете промпт в чат и вставляете ответ обратно |
| Объём | весь корпус за один запуск, в пределах лимитов Groq | удобно по 10-20 инструкций |
| Интернет | нужен | нужен только чату |

**Через Groq.** Создайте ключ на [console.groq.com](https://console.groq.com) в разделе API Keys и вставьте его во вкладке «Настройки», блок «Языковая модель – ключ Groq» (поле есть и во вкладке «Рубрика», но она открывается только после загрузки данных). Нажмите «Проверить ключ», затем выберите, какие инструкции оценить, и нажмите «Оценить через Groq». Ключ хранится только в вашем браузере и не попадает в экспорт. Если проверка сообщает об ошибке связи, откройте инструмент с GitHub Pages или воспользуйтесь ручным способом.

**Вручную.** Нажмите «Скопировать промпт», вставьте его в чат, скопируйте ответ модели в поле «Ответ модели», укажите модель и версию и нажмите «Импортировать».

Для проверки стабильности модели запустите одну и ту же выборку трижды. В ручном способе укажите в поле «Прогон» номер (прогон 1, прогон 2), прогоны Groq получают дату в названии.

### Согласованность

Внизу вкладки выберите двух оценщиков – двух экспертов, эксперта и модель или два прогона модели. Инструмент покажет по каждому критерию число пар оценок, долю точных совпадений и взвешенную каппу Коэна. Каппа ниже 0,41 сигнализирует, что формулировку критерия в рубрике нужно уточнить.

## Режим «Тексты»

Режим «Тексты» анализирует тексты для чтения, скрипты аудирования, диалоги и языковой материал упражнений тем же ядром, что и инструкции. Переключатель «Инструкции / Тексты» находится в шапке рядом с названием, вкладки остаются прежними, а их содержание зависит от режима. Инструмент помнит выбранный режим и загруженные тексты между сеансами. При первом запуске загружается пример – 10 текстов к тем же двум вымышленным учебникам.

### Как добавить тексты

1. Переключитесь в режим «Тексты» и откройте вкладку «Данные».
2. Заполните учебник, уровень, урок, номера упражнений и тип текста. Заголовок и источник (аутентичный, адаптированный, составлен автором) заполняются по желанию.
3. Вставьте текст целиком и нажмите «Добавить текст». Другие способы – кнопка «Загрузить .txt или .docx» (каждый файл становится отдельным текстом, заголовок берётся из первой короткой строки или имени файла) и режим «Таблица CSV» для многих текстов сразу.
4. Нажмите «Анализировать». Текст в списке можно изменить или удалить.

Абзацы разделяются пустой строкой, реплики диалога пишутся с новой строки (A: …, Tom: …). Имена говорящих, пропуски \_\_\_ и номера пропусков в расчёт не входят. Файлы PDF и сохранённые веб-страницы тоже загружаются – в поле попадает весь текст файла, лишнее (заголовки упражнений, колонтитулы) удалите через «Изменить».

### Связь текста с инструкцией

Поле «Упражнения» содержит номера упражнений, к которым относится текст («2», «1, 2», «1-3»). Инструмент ищет среди загруженных инструкций упражнения с тем же учебником, уроком и номером и составляет пары «инструкция – текст». Название учебника и урока должно совпадать с данными инструкций, поэтому учебник удобно выбирать из подсказки в поле. Столбец «Инструкций» в списке текстов показывает, сколько пар нашлось, ноль указывает на расхождение в названиях или номерах.

### Таблица CSV для текстов

| Поле | Обязательное | Допустимые названия |
| --- | --- | --- |
| text | да | текст, script, скрипт |
| book | да | textbook, учебник |
| level | да | cefr, уровень |
| unit | да | lesson, урок |
| ex | для пар | exercises, упражнения |
| text\_type | желательно | type, тип текста (reading, listening, dialogue, material или русское название) |
| title | по желанию | заголовок |
| source | по желанию | источник |

Текст с переносами строк заключается в кавычки. Образец – examples/sample-texts.csv.

### Что показывают вкладки

- **Тепловая карта** имеет три вида. «Тексты» – показатели T1 лексика, T2 грамматика, T3 синтаксис, T4 читаемость (справочно), индекс сложности текста (ИСТ) и оценка уровня L, а при выборе эксперта или модели – рубрика TR1-TR6. «Уроки» – сводная карта, где рядом со средними показателями текстов стоят средний ИСВ инструкций того же урока, разность ИСВ − ИСТ и среднее R6. «Пары с инструкциями» – для каждой пары уровни лексики и грамматики инструкции и текста, оба индекса и показатель R6 (0,5 – инструкция на уровень сложнее текста и заявленного уровня, 1 – на два и более).
- **Карточка текста** открывается кликом по строке. Текст показан по абзацам, полоса слева окрашена по ИСТ абзаца, слова и конструкции выше уровня подсвечены так же, как в карточке инструкции. Ниже – карта абзацев, показатели, составляющие оценки уровня, профиль лексики с накопленным покрытием, замечания, связанные инструкции, рубричные оценки, список слов выше уровня и грамматика. Карточка инструкции в режиме «Инструкции» теперь тоже показывает её текст и сравнение для R6.
- **Статистика** – профиль лексики корпуса, число текстов выше и ниже порогов покрытия 95 и 98 %, синтаксис и разнообразие, оценка уровня каждого текста, карты по учебникам, урокам и типам текстов, сводка «инструкции и тексты по урокам». Выгрузки – результаты CSV, пары CSV и протокол JSON.
- **Выводы** описывают лексику, грамматику, синтаксис, уровень текстов и пары с инструкциями. Вывод о парах появляется и в режиме «Инструкции», если тексты загружены.
- **Настройки** делятся на общие и собственные. Общие (уровень, список лексики, A7, источник уровней грамматики, слова вне списка) действуют в обоих режимах, так что инструкции и тексты измеряются одной мерой. Собственные – пороги покрытия, допуск по грамматике, веса ИСТ и оценки уровня, нормы синтаксиса с расчётом по корпусу. Словник учебника общий и загружается во вкладке «Данные».
- **Рубрика** в режиме «Тексты» содержит критерии TR1-TR6 (тема и задача, аутентичность, культурная доступность, связность, уровень текста и задания, пригодность для аспекта). Экспертная оценка, Groq и ручной промпт работают как для инструкций, оценки двух режимов хранятся отдельно. Тексты длиннее инструкций, поэтому Groq получает их пакетами по 2, а в ручном способе удобно отправлять 3-5 текстов за раз.
- **Методика** показывает формулы режима с текущими значениями настроек.

Подробное обоснование показателей – в документе «Научное обоснование и методика», раздел 6.

## Синтаксический разбор

Без разбора анализатор определяет грамматику и придаточные по своим правилам. Для исследовательской выборки разбор лучше подготовить внешним анализатором – spaCy или Stanza. Анализатор принимает и любой другой файл в формате CoNLL-U, например результат UDPipe.

### Как подготовить разбор

1. Откройте вкладку «Данные», найдите блок «Синтаксический разбор» и нажмите «Скачать тексты для разбора». В файл `texts-for-parsing.jsonl` попадут все инструкции и тексты, которые сейчас загружены.
2. Один раз установите spaCy и модель. В терминале выполните `python3 -m pip install spacy`, затем `python3 -m spacy download en_core_web_sm`.
3. Перейдите в папку анализатора и выполните `python3 tools/parse_texts.py ~/Downloads/texts-for-parsing.jsonl -o parsed.conllu`. Для Stanza добавьте `--engine stanza` (сначала `python3 -m pip install stanza`), для другой модели spaCy – например, `--model en_core_web_trf`.
4. Нажмите «Загрузить разбор» и выберите `parsed.conllu`.

Под кнопками появится строка о том, для скольких инструкций и текстов найден разбор, сколько конструкций разбор добавил и сколько срабатываний правил снял. Анализатор, его версия и модель записываются в файл разбора и в протокол JSON.

### Что меняется

- Срабатывания правил сверяются с частями речи. Если правило приняло причастие за прошедшее время (the students selected), разбор его снимает.
- Добавляются конструкции, которые правила пропускают, – настоящее простое время, повелительное наклонение, Past Simple у форм read, put, cut после любого подлежащего, каузатив и глаголы восприятия с любым дополнением, определительное придаточное без союзного слова (the book I read).
- В режиме «Тексты» придаточные для T3 считаются по дереву зависимостей.
- Повелительное наклонение в режиме «Инструкции» не входит в критерий A2, так как это жанровая форма инструкции.

В карточке срабатывания по разбору помечены словом «разбор», а под списком конструкций указано, что снято и почему.

### Сравнение с правилами

Отметка «Учитывать разбор при анализе» включает и выключает разбор без повторной загрузки файла. Так можно рассчитать показатели обоими способами на одних и тех же данных и сравнить их.

### Если разбор не применился

Разбор сопоставляется с записью по тексту. Пробелы, переносы строк и вид кавычек при этом не важны, но любая правка слов после разбора делает его неприменимым. Тогда снова скачайте тексты и повторите разбор. Если слова разбора совпали с токенами анализатора меньше чем на 80 %, запись анализируется только правилами, а в карточке появляется пояснение.

Файл разбора хранится в браузере отдельно от остальных данных. Очень большой файл браузер может не сохранить, тогда после перезагрузки страницы его нужно загрузить снова, и блок разбора об этом предупреждает.

## Экспорт, хранение и публикация

### Экспорт

| Файл | Где | Что внутри |
| --- | --- | --- |
| Результаты CSV | Статистика | строка на инструкцию – метаданные, подсчёты, списки слов и конструкций, все показатели; открывается в Excel, SPSS, R, Jamovi |
| Протокол JSON | Статистика | версии эталонов, настройки, полный разбор каждой инструкции, рубричные оценки, выводы – для воспроизведения |
| Выводы .txt | Выводы | текст автоматических выводов |
| Оценки JSON | Рубрика | оценки экспертов и моделей – для передачи между компьютерами |
| Промпт .txt | Рубрика | текст для языковой модели |

### Где хранятся данные

Инструкции, настройки и оценки хранятся в памяти браузера на вашем компьютере и никуда не отправляются, кроме случая, когда вы сами запускаете оценку через Groq. У этого есть три следствия.

- Версия из папки и версия с GitHub Pages хранят данные раздельно.
- Очистка истории браузера с данными сайтов удалит и оценки.
- Регулярно сохраняйте протокол JSON и оценки JSON в папку исследования – это и есть резервная копия.

### Публикация на GitHub

Папка Textbook Analyzer уже подготовлена – исходные файлы CEFR-J лежат в `data/`, служебные файлы исключены через `.gitignore`.

1. На github.com нажмите **New repository**, задайте имя (например, textbook-analyzer) и выберите Public.
2. В пустом репозитории нажмите **uploading an existing file** и перетащите всё содержимое папки Textbook Analyzer (папки js, data, examples, docs и файлы в корне). Нажмите **Commit changes**.
3. Откройте **Settings – Pages**, в блоке Build and deployment выберите Deploy from a branch, ветку main и папку / (root), нажмите Save.
4. Через 1-2 минуты на той же странице появится ссылка на инструмент.
5. Чтобы обновить версию на GitHub, снова загрузите изменённые файлы через **Add file – Upload files** – они заменят старые.

До публикации выберите лицензию на код (чаще всего MIT) – GitHub предлагает её при создании репозитория. Данные CEFR-J и Octanove сохраняют свои условия, они описаны в `data/README.md`.

### Частые вопросы

**Можно ли работать с компьютера после публикации?** Да. Папка на компьютере остаётся полноценным инструментом, GitHub – лишь его публичная копия.

**Инструмент показывает старые данные.** Он восстанавливает последний сеанс. Чтобы начать заново, нажмите «Очистить» во вкладке «Данные».

**Слово помечено неверно.** В карточке видно источник уровня. Если слово употреблено в учебном значении, добавьте его в словарь инструктивных значений. Если авторы вводят его в учебнике, загрузите словник. Каждое такое решение стоит описать в методике.

**Где ввести ключ Groq?** Во вкладке «Настройки», первый блок «Языковая модель – ключ Groq». Там же выбирается модель по умолчанию и проверяется ключ. Ключ общий для оценки по рубрике и для импорта инструкций.

**У меня учебник в PDF, Word или на сайте – как его загрузить?** Через блок «Импорт из учебника» во вкладке «Данные», см. раздел «Импорт из учебника». Таблицу или JSON готовить не нужно.

**Модель вернула нечитаемый ответ.** Инструмент сообщит, для скольких инструкций ответ не разобран. Запустите оценку ещё раз с вариантом «Без оценки модели» или выберите более крупную модель.
