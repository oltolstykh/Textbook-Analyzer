# Исходные данные эталонов

Эти файлы – исходники встроенных эталонов анализатора. Сам инструмент читает их из `js/cefrj.js`, куда данные перенесены без изменений, поэтому CSV нужны для проверки и воспроизведения, а не для работы инструмента.

| Файл | Что это | Версия | Условия использования |
| --- | --- | --- | --- |
| `cefrj-vocabulary-profile-1.5.csv` | The CEFR-J Wordlist (уровни A1-B2, 7 799 строк) | 1.5 | бесплатно для исследовательских и коммерческих целей при корректной ссылке; авторские права – Tono Laboratory, Tokyo University of Foreign Studies |
| `octanove-vocabulary-profile-c1c2-1.0.csv` | Octanove Vocabulary Profile (уровни C1-C2, 2 136 строк) | 1.0 | Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0) |
| `cefrj-grammar-profile-20180315.csv` | The CEFR-J Grammar Profile (500 пунктов) | 20180315 | бесплатно для исследовательских и коммерческих целей при корректной ссылке; авторские права – Tono Laboratory, Tokyo University of Foreign Studies |

Источник файлов – https://github.com/openlanguageprofiles/olp-en-cefrj
